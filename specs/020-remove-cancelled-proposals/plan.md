# Implementation Plan: Remove Cancelled Proposals

**Branch**: `feature/remove-cancelled-proposals` | **Date**: 2026-11-18 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `/specs/020-remove-cancelled-proposals/spec.md`

## Summary

Let a person delete cancelled multisig proposals from this device: a per-item "Remove from list", and a "Clear all cancelled" action behind a confirmation. A new wallet-service method deletes only cancelled proposals from local storage; the Pending page adds the two actions. Because the Activity feed reads the same stored list, removal also clears Activity entries. Most of this is already built; the remaining work is the missing tests (Constitution III), a browser check, and a docs line.
