# common-passwords.txt

Deny list for passphrase setup (specs/009-stronger-pin-protection, research R6). One lower-cased entry per line;
only entries of 12 or more characters matter, because shorter passphrases are rejected by the length rule first.

**Status: starter list.** This file currently holds a short hand-written list of well-known weak long passphrases.
Task T032 replaces it with a compact list of about 10,000 entries drawn from a published common-password source
(candidate: SecLists, MIT licence); record the exact source, version and licence here when that is done.
